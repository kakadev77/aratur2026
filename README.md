# AraTur 2026 — versão restaurada

Reconstrução do front-end com base no vídeo e nas referências originais do projeto.

## Rodar

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite (normalmente http://localhost:5173).

## Estrutura
- React + Vite + TypeScript
- One-page responsiva
- Seções: Início, Sobre, Pontos turísticos, Cultura e história, Onde comer, Onde ficar, Eventos e Localização
- Imagens locais em `public/images`
